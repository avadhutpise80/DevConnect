# DevConnect

DevConnect is a Django-based developer community platform where developers can create profiles, share posts, showcase projects, and connect with other developers.

## Features

- User registration and login
- Developer profiles
- Edit profile information
- Account deletion
- Community member listing
- Create, edit, and delete posts
- Post ownership protection
- Create, edit, and delete projects
- Project ownership protection
- GitHub and live project links
- Django admin panel
- Responsive UI with Bootstrap

## Tech Stack

- Python
- Django
- SQLite
- HTML
- CSS
- Bootstrap
- Git
